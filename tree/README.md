# Arbre d'exemple

`home/` est un exemple fictif. Ses adresses utilisent des plages réservées à la
documentation, ses alias SSH utilisent le domaine `.invalid` et ses commandes
VM sont sans effet. Ce n'est pas un inventaire opérationnel.

Générer des nœuds propres à un déploiement depuis une spécification JSON relue
avec `modops new` ou `modops render`. Ne pas versionner d'hôtes, réseaux ou
identifiants privés dans un arbre public.
